# 霁哥霓虹枪战 (3D)

横屏手机优先的 3D 霓虹第一人称射击游戏。

## 操作
- **手机横屏**：左侧虚拟摇杆移动，右侧滑动瞄准，右下角按钮射击
- **PC**：WASD 移动，鼠标锁定后瞄准，左键/空格射击，R 使用回血

## 胜利条件
- 到达绿色大撤离点 **或** 消灭全部敌人

## 改动要点
- 真正 3D 空间 + Three.js
- 程序化仿真人形敌人（头身四肢+发光眼）
- 首页显示「霁哥霓虹枪战」+ 开始游戏
- 撤离点更大且每次随机位置
- 敌人数量上调（42），回血道具下调（5）
